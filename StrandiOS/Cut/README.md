# Cut (from zhoop)

`CutPlanStore.swift`, `CutTodayView.swift` and `CutSleepView.swift` come unchanged from
[hackyguru/zhoop](https://github.com/hackyguru/zhoop), a weight-loss fork of NOOP under the same
PolyForm Noncommercial 1.0.0 license. In this personal build they sit under More → Body next to
NOOP's own screens. `CutPlanStore+Push.swift` is new here: it hands the food log, weigh-ins and plan
to the self-hosted push (Strand/Data/SelfHostedPush.swift).
